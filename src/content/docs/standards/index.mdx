import { Badge, Steps } from '@astrojs/starlight/components';

这本指南只服务一件事：让还没有关键词、还没有网站的人，按顺序做出第一份能上线的页面。下面是收录边界。新增页面之前，先用文末模板自检。

## 写给谁

读者同时满足这三条：

- 还没有一个已经决定要做的关键词。
- 还没有一个已经上线的网站。
- 需要的是步骤、清单和可复制的空表，而不是行业评论。

已经有站、要做第二语言或要放大投放的人，不在这一版的范围内。

## 收录什么

一页要同时满足下面四条，才放进侧边栏：

1. 属于这五步之一：选词、建站、域名部署、内容、获客。
2. 读者做完能拿出一个具体产物：一张表、一个页面、一次上线记录或一条获客记录。
3. 步骤能在不购买付费 SEO 工具的情况下做完。谷歌搜索、搜索框下拉、相关搜索、谷歌趋势、搜索控制台，算免费的基本动作。
4. 正文是步骤、清单或模板。背景只保留理解下一步所必需的几句。

## 不收清单

下面这些不写进正文，也不在侧边栏单开一页：

- 没有步骤的观点文、经历复盘、行业展望。
- 付费课程、社群、咨询的报名页和限时优惠。
- 付费英文 SEO 工具的横评、折扣和使用教程。
- 第一个主页面还没写完就出现的批量铺页、外链购买、矩阵站。
- 和这五步无关的工具新闻、模型新闻。

一篇稿子如果主要在比较工具价格，或主要在劝人报名，就停在这一页，不往下写。

## 一页的最低结构

<Steps>

1. 第一段写清这一步的产物，以及没做出产物时要停在哪。

2. 步骤用有顺序的动作写成。每步只做一件事，并写上结果填到哪里。

3. 需要读者照抄的空表，标上 <Badge text="模板" variant="tip" />，空位用 `TODO`。

4. 还没核对的名单、价格、截图流程，标上 <Badge text="待填" variant="caution" />，并写明缺的是什么。不要先填一个过期数字占位。

5. 配一张清单页，清单的每一项都能被另一个人勾选或打回。

</Steps>

## 新开一页时复制

<Badge text="模板" variant="tip" />

复制到草稿里。`TODO` 还在，就还不能合并进侧边栏。

```md
## 页面名称
TODO

## 它属于哪一步
选词 / 建站 / 域名部署 / 内容 / 获客

## 做完的人手里有什么
TODO

## 步骤
1. TODO：动作
   做完后填到：TODO

## 若这篇不该进指南，原因写在这里并停笔
TODO
```
