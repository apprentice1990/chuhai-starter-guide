这一步的产物是一个用 https 打开的地址，以及你写下来的「主地址」。自定义域名可以后买。买了以后，全站只留一个主主机名，另一个跳过来。

开始前，[建站清单](/build/checklist/) 要已经勾完：本地的首页、主页面、关于页都能打开。

## 步骤

<Steps>

1. **先部署，后买域名**

   把代码放到 Git 仓库，用托管平台发布，先拿到平台分配的 https 地址。用这个地址把三页都点开。三页都能打开，再决定是否买域名。

2. **若使用 Vercel，并且站点是 Astro，按这张表设置**

   本指南仓库也用这张表。你的出海站如果不用 Astro，只改构建命令和输出目录，其余检查不变。

   | 项目设置 | 填写 |
   | --- | --- |
   | Framework Preset | Astro |
   | Install Command | `npm install` |
   | Build Command | `npm run build` |
   | Output Directory | `dist` |
   | Node.js Version | 22.x |

3. **需要自己的域名时再买一个**

   买一个你拼得出来的名字，优先短的 `.com`（还能注册、你也付得起的时候）。一次买一个。词表里标着「再观察」的说法，先不要各买一个域名。

4. **只保留一个主地址**

   在托管后台把主主机名定下来（带 `www` 或不带，二选一）。另一个主机名跳到主主机名。页面上的绝对链接、以后的 sitemap，都用这一个主地址。

5. **域名定了之后再打开 sitemap**

   在 Astro 配置里把 `site` 写成 `https://` 加上你的主主机名，重新构建并部署。构建产物里会出现 sitemap。域名还没定的时候，配置里不要写 `site`。本指南现在就是这样：构建日志里的 sitemap 跳过提示是预期结果。

6. **把主地址交给搜索控制台**

   站点用主地址能打开之后，在谷歌搜索控制台里验证这一个主地址。sitemap 已经生成，再提交 sitemap 地址。还没有 `site`、还没有 sitemap 文件时，先不要提交。

</Steps>

## 上线后当场核对

- 地址栏是 https，浏览器没有证书警告。
- 首页、主页面、关于页用线上地址都能打开。
- 刷新主页面不会掉进平台的 404。
- 页面标题是你写的句子，不是模板自带的 “My Docs” 或 “Welcome”。
- 带 `www` 和不带 `www` 最后都停在同一个主地址。
