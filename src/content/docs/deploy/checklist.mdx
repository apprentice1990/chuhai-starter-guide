对照 [域名与部署](/deploy/) 做。

## 进入这一步之前

- [ ] 本地首页、主页面、关于页都能打开
- [ ] 代码已经放进 Git 仓库

## 第一次上线

- [ ] 托管平台给出了一个 https 地址
- [ ] 用这个地址打开了首页、主页面、关于页
- [ ] 刷新主页面后内容还在
- [ ] 若站点是 Astro：Framework Preset 是 Astro，Build Command 是 `npm run build`，Output Directory 是 `dist`，Node.js 是 22.x

## 主地址

- [ ] 写下了唯一的主地址（平台域名，或你已经买好的域名）

```text
主地址：TODO
```

- [ ] 若买了域名：只买了一个，并且带 www 与不带 www 会停在这一个主地址
- [ ] 地址栏是 https，没有证书警告
- [ ] 线上页面标题是你写的，不是脚手架默认标题

## sitemap 与搜索控制台

- [ ] 域名还没定：配置里的 `site` 保持为空，构建跳过 sitemap，你没有提交 sitemap
- [ ] 域名已经定了：`site` 已写成 `https://` 加主主机名，重新部署后 sitemap 能打开
- [ ] 搜索控制台验证的是这一个主地址
- [ ] 只在 sitemap 文件存在时提交了它

## 过关

主地址能稳定打开三页之后，去 [内容](/writing/) 把主页面写完。主页面还是模板空位时，先不要做 [获客](/acquire/)。
