对照 [获客](/acquire/) 做。前面的空着，后面先不要勾。

## 进入这一步之前

- [ ] 主页面的线上地址能打开
- [ ] 在线上正文里搜索不到 `TODO`
- [ ] 链接准备指向主页面，而不是首页

```text
主页面地址：TODO
```

## 一次有用的回复

- [ ] 找到了词表来源里的原讨论，或一处仍有人提出同一任务的讨论
- [ ] 回复先写清怎么做完任务，链接在回答后面
- [ ] 这一处之前没有贴过同一个链接
- [ ] 记录表新增了一行，日期、地点、回复做了什么、链接都填了

## 先停在这里的情况

- [ ] 还没有核对过的目录名单，就还没有批量提交目录
- [ ] 搜索控制台还没有展示，就还没有按词表去加第二页
- [ ] 主页面收到「看不懂」的回复时，先改 [内容](/writing/)，再继续贴链接

## 过关

一条完整记录，就是这一步的过关。下一条记录用同一张表继续加行。
