复制到你的笔记或表格。这页不保存内容，勾选刷新也会丢。免费填法在 [选词](/keywords/)，量、KD、CPC 的填法在 [完整闸门](/keywords/full-gate/)。

结论只用这三个词：`先做`、`先不做`、`再观察`。整张表 `先做` 只能出现一次，而且得你自己写。

表头备注先写 KD 档：`严档 0–29` 或 `宽档 小于 40`。没走完整闸门就写 `只走免费`。

## 空表

```csv
候选说法,从哪听来的,想完成什么,下拉或相关搜索,allintitle,Volume,KD,CPC,KDROI,KGR,前10条,结论,备注
```

KGR 用 `intitle` 的个数除以 Volume，和 allintitle 那一列分开。算法在 [两个公式](/keywords/formulas/)。

## 示例

一句真有人会搜的英文：把文字贴进去，看平均一句有多长。第一站可以练这种一页小工具。它不是指定题目。量、KD、CPC 不写死，有工具你再填。

`readability calculator`、`word counter` 另开一行，先标「再观察」。这就是同一需求的另一种说法。你两周内真做得完其中一行，再改成「先做」，并把别的「先做」改掉。

## 填完再看

- [ ] 这一行的任务别人看得懂
- [ ] 「先做」那一行没有留下 `TODO`
