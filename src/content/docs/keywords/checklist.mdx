对照 [选词](/keywords/) 做。勾选框刷新就没了，请打在你自己的笔记里。

免费部分做完就能建站。有 Semrush 的，把「完整闸门」也勾完再标「先做」。没有账号的，用 Keyword Planner、谷歌 `intitle:` 和 Trends 代替，并在笔记里写「免费替代」。

[候选词表](/keywords/sheet/)里「先做」恰好一行，而且是你写的，再打开 [建站](/build/)。

## 范围

- [ ] 写了两周内能讲清的题目
- [ ] 写了两周内能上线的一页：说明，或一个很小的免费工具
- [ ] 写了这版不做的

## 免费入门

- [ ] 至少 10 行，每行有来源：自己会搜、别人的原话、下拉、相关搜索
- [ ] 每行写了要完成的事；写不出的已经标「先不做」
- [ ] 留下的每行都看过下拉和相关搜索；两项都空的已经标「先不做」
- [ ] 每行搜过 `allintitle:`，个数只和本表其他行比
- [ ] 每行看过趋势最近 12 个月；一根尖刺的已经标「再观察」，没有标「先做」
- [ ] 留下的每行都看了前 10 条，并写了是说明、对照，还是小工具

## 完整闸门

没有 Semrush 的，把对应项改成免费替代再勾。

- [ ] 【Semrush 或谷歌下拉】种子用了工具尾巴：generator、converter、calculator、checker、remover、compressor 里至少一种
- [ ] 先看了过去 7 天的上升，再切到过去 12 个月
- [ ] 12 个月平、最近才翘的，已经当假涨丢掉
- [ ] 【Semrush 或 Keyword Planner】量写进表。备注写了用的是「不低于 600」还是「大约 1K 到 10K」
- [ ] 备注写了 KD 用严档（0 到 29）还是宽档（小于 40），一张表只用一档
- [ ] CPC 看过。低于 0.1 的没有被单独杀掉，备注里有「CPC 低」
- [ ] `near me`、品牌、人名、新闻和体育尖刺，已经标「先不做」
- [ ] 有量的行算了 KDROI 和 KGR；没量的行这两格是空的
- [ ] 前 10 条亲手点开。大媒体、官方教程垄断、意图不对、AI 概览已经答完的，已经标「先不做」
- [ ] 同一个需求至少收了两种英文说法，并且分开过闸门
- [ ] （可选）【Similarweb】从站反查的词，重新走过趋势、量和前 10 条

## 只留一个

- [ ] 「先做」恰好一次，是你自己标的，不是照着案例抄的
- [ ] 这一行的任务、下拉或相关搜索、能不能做，都不是空的
- [ ] 其他还能做的标成了「再观察」
- [ ] 还没为这些词买域名

## 过关

上面在笔记里勾完之后，把这一行抄进笔记，再去建站：

```text
先做的说法：TODO
这一页要帮人完成：TODO
页面类型：说明 / 对照 / 小工具
用的闸门：免费 / 严档 KD / 宽档 KD
```
