对照 [选词](/keywords/) 做。这些勾选框刷新就没了，请在你自己的笔记里打勾。

[候选词表](/keywords/sheet/)里「先做」恰好一行，再打开 [建站](/build/)。

## 范围

- [ ] 写了两周内能讲清的题目
- [ ] 写了两周内能上线的一页：说明，或一个很小的免费工具
- [ ] 写了这版不做的

## 词表

- [ ] 至少 10 行
- [ ] 每行有来源：自己会搜、别人的原话、下拉、相关搜索
- [ ] 每行写了要完成的事；写不出的已经标「先不做」

## 及格线

- [ ] 留下的每行都看过下拉
- [ ] 留下的每行都看过相关搜索；两项都空的已经标「先不做」
- [ ] 每行搜过 `allintitle:`，个数只和本表其他行比
- [ ] 每行看过趋势最近 12 个月；一根尖刺的已经标「再观察」，没有标「先做」

## 能不能做

- [ ] 留下的每行都看了前 10 条
- [ ] 「能」的行写了是说明、对照，还是小工具
- [ ] 「不能」的行写了缺资料、手艺，还是时间

## 只留一个

- [ ] 「先做」恰好一次
- [ ] 这一行的任务、下拉或相关搜索、能不能做，都不是空的
- [ ] 其他还能做的标成了「再观察」
- [ ] 还没为这些词买域名

## 过关

上面都在笔记里勾完之后，把这一行抄进笔记，再去建站：

```text
先做的说法：TODO
这一页要帮人完成：TODO
页面类型：说明 / 对照 / 小工具
```
