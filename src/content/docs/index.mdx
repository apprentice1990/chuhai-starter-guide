## 每一步要留下什么

| 步骤 | 做完时你手里有 |
| --- | --- |
| 选词 | 一张至少 10 行的词表，恰好一行结论是「先做」 |
| 建站 | 本地能打开的首页、主页面、关于页 |
| 域名部署 | 一个 https 地址；自定义域名可以后补，但只能有一个主地址 |
| 内容 | 主页面回答完那一个任务，并写上更新时间 |
| 获客 | 一条记录：在哪里、对谁、说了什么、链到哪一页、哪一天 |

## 页面上的两个标记

<Badge text="待填" variant="caution" /> 这一格还空着。空着的原因写在旁边：有的要你填自己的词，有的是本站还没核对完。看到 `TODO` 就当空位，不要把 `TODO` 原样发布到你的网站上。

<Badge text="模板" variant="tip" /> 这一段可以整段复制到你自己的笔记、表格或页面里，再把空位填上。

## 怎么用

1. 先读 [收录标准](/standards/)，确认你要做的是一份能执行的清单。
2. 从 [选词](/keywords/) 开始，用 [选词清单](/keywords/checklist/) 勾完再往下。
3. 每步的清单有一项没勾，就停在那一步。
4. 侧边栏的顺序就是执行顺序。
